Preview:
1. Extract the ZIP.
2. Open index.html in a browser.

Free hosting with GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html, style.css, script.js, and the whole assets folder.
3. In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Use the URL GitHub provides once published.

Privacy:
If the repository is public, anyone with the link may be able to view the photos. Use a private hosting option if that matters to you.
